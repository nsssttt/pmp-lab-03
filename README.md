# Лабораторна робота 03

Програмування мобільних пристроїв. LinearLayout і FrameLayout.

Приклади вкладених LinearLayout та накладання елементів у FrameLayout. Кнопка перемикає приклади.

## Запуск

Відкрити папку проєкту в Android Studio та запустити `app`. Для збірки потрібні Android SDK 35 і Build-Tools 36.0.0. У Windows також можна виконати `./build.ps1` з налаштованими Java та Android SDK.

Готовий застосунок: [lab03-debug.apk](apk/lab03-debug.apk). Працює на Android 8.0 та новіших версіях.

Java-код і XML-файли містяться в `app/src/main/`.
